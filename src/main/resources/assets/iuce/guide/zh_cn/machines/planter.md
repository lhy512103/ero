自动温室。上格放种子或树苗，下格放土壤，持续产出作物。

- 电压：LV
- **数据配方**（见下方）会消耗种子和土壤。
- **自动识别**的作物不消耗种子：小麦、胡萝卜、甜菜、可可、甘蔗、仙人掌、竹子、瓜类、浆果等，也包括其他模组的普通作物。
- 树苗长成对应的原木；花、蘑菇、藤蔓、睡莲等每 30 秒繁殖出一个。

## 昼夜

| 时段 | 速度 |
| --- | --- |
| 凌晨 | 1.5 倍 |
| 清晨 | 2 倍 |
| 正午 | 3 倍 |
| 下午 | 2 倍 |
| 夜晚 | 1 倍，耗电翻倍 |
