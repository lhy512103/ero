天然橡胶工艺线把生乳胶加工成工业橡胶，再做成传送带和密封件。它比提取机的橡胶更高级，是二级物流的原料。

{flow: iuce:raw_latex -> @iuce:coagulation_tank -> @iuce:sheeting_press -> @iuce:smokehouse -> @iuce:rubber_mixer -> @iuce:vulcanizer -> iuce:rubber_belt}

## 步骤

1. [凝固槽](plastic/coagulation_tank)：生乳胶加乳酸发酵液凝固成凝块。乳酸液来自发酵罐。
2. [压片机](plastic/sheeting_press)：把凝块压成胶片，挤出工艺水。
3. [烟熏房](plastic/smokehouse)：用原木烟熏胶片，得到橡胶。
4. [密炼机](plastic/rubber_mixer)：橡胶、硫磺（洗涤塔脱硫副产）和焦粉混炼成混炼胶。
5. [硫化机](plastic/vulcanizer)：用蒸汽硫化成橡胶传送带或橡胶密封件。

> [!NOTE]
> 硫化让橡胶分子之间形成交联，弹性和耐磨性大幅提高，这也是轮胎和传送带的基本工艺。
