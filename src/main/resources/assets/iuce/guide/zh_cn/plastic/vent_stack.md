安全排放：烧掉可燃气体、放空无用气体，避免储罐憋满导致停机。

## 规格

- 电压：LV，内部缓存 1000 EU
- 物品：输入 0 格，输出 0 格
- 流体：输入 1 槽，输出 0 槽（每槽 8000 mB）
- 升级槽：0 个
