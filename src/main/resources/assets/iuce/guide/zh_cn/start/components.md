机器不是外壳加电路板就能造的，每台机器都要用到下面这些零件。

## 基础零件

{recipe: iuce:copper_coil, iuce:electric_motor, iuce:iron_gear, iuce:heating_coil}

| 零件 | 用在哪里 |
| --- | --- |
| {item:iuce:electric_motor} | 几乎所有低压机器、升级、电动工具 |
| {item:iuce:iron_gear} | 打粉机、金属成型机、机器升级组件 |
| {item:iuce:heating_coil} | 电炉、感应炉、地热发电机（需要镍棍） |
| {item:iuce:copper_coil} | 马达、加热线圈、变压器、CESU |

## 青铜与钢之后

{recipe: iuce:bronze_rotor, iuce:bronze_gear, iuce:advanced_motor, iuce:electrode}

{item:iuce:bronze_rotor} 是洗矿机和泵的门槛；{item:iuce:magnet} 只能在 [感应炉](machines/induction_furnace) 里做；{item:iuce:electrode} 用来造 [电解机](machines/electrolyzer)。
