# 多方块工业外观

新版外观与结构随 IUCE 本体加载，不需要资源包。如果曾启用旧拉丝钢试样，请先禁用它，以免它遮住本体的模型。

- **选矿联合厂**：宽 11、高 11、长 15；有高塔、开放式洗选段、末端双立筒和外露管路。
- **轧制联合机**：宽 9、高 7、长 9–17；有开放辊床、跨线门架与尾端机组。延长时增加辊床和门架，末端部件随长度移动。

参考 [GTCEu Modern 的多方块规则](https://gtwiki.miraheze.org/wiki/Multiblocks_(Modern))：轮廓由固定工艺部件与可换仓位共同决定，而不是一圈万能外壳。材质取自 IUCE 原有单方块机器的设计语言：浅色搪瓷、深色机芯、冷青指示灯，局部使用琥珀色端子。没有导入 GTCEu 的纹理、模型或代码。

`PlantStructure` 同时供成型校验、投影、施工机、材料清单和指南使用。梁与滚筒按轴校验，旧存档中的控制器保留旧结构规则；重新放置控制器会使用新规则。外壳在同类外壳或仓口相接的一侧隐藏边条，由相邻方块变化触发；不需要第三方 CTM，也不包含对角内圆角网络。控制面亮绿表示结构成型，不代表滚筒在转。

- `python tools/draw_plant_parts.py`：重新生成项目内的像素贴图和连接收边模型。
- `gradlew.bat runClient -PsmokeTest -PregressionTests -PguideShots=industrial -PguideWorld=<临时测试世界>`：在独立的临时测试世界搭建两台示例并输出游戏内截图；此命令会改动指定测试世界，不要传入日常存档。
