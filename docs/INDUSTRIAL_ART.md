# 多方块工业外观试样

## 试用

运行 `python tools/draw_industrial_preview.py`，把 `build/iuce-industrial-preview.zip` 放进 Minecraft 26.1.2 实例的 `resourcepacks`，并在游戏中启用。禁用后恢复原样。生成脚本只用 Python 标准库，无需安装图像库。

试样包括拉丝钢外壳、进出料口、两档能源仓，以及选矿联合厂和轧制联合机各自的未成型、已成型控制面。全部为原创 16×16 像素图。资源包覆盖显示模型，不改方块 ID、碰撞、配方、结构判定、投影或存档。仓口保持各面可见，不暗示它只有一个可连接方向。控制器亮灯表示成型，不表示正在加工。

## 下一轮：先改轮廓，再做连接纹理

| 机器 | 建议轮廓 | 玩家从外观读到什么 |
| --- | --- | --- |
| 选矿联合厂 | 低而宽的双层底座，沿长度分成高料斗、较低的洗选槽、独立出料段。顶面留出落差，不把全部工位封进同一层平顶里。 | 从料斗、槽体到出料口能辨认物料方向；控制柜在侧面，不占据整面正立面。 |
| 轧制联合机 | 两条长底梁配进料辊台、重复门架和尾部电机舱。长度只增加标准辊架段，两端样式固定。 | 加长看起来是在加工作位，而不是延长一面墙；换模和维护位置易找。 |

1. **用骨架确定形状。** 先做基座、立柱、围板、工艺部件四类几何。重点部件用轮廓区别，颜色只做功能提示；警示条留在检修口和运动件附近。
2. **用面内邻接做真正的连接。** 先原型化四边的 `16` 种遮罩：无邻接、贯通、端点、外边、外角；有必要时再补对角邻接与内角。只对同族、同平面且视觉连续的面接板，转角交给框架。仓口使用和外壳一致的底材，再叠功能面，避免一放仓口整圈断缝。
3. **把结构改造当成独立功能。** 当前两台机器都用 `PlantControllerBlockEntity.shell` 的矩形外壳。下一版优先让选矿厂用带局部高度和指定部件位置的结构模板，再让校验、图纸投影、材料清单、施工机和指南读同一模板；已成型的旧矩形不应在升级时突然失效。

当前试样是**无显眼分格线的可平铺材质**，不读取相邻方块，不是连接纹理，也没有改变整体轮廓。
