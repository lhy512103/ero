## 1. 定位与核心循环

**从一把锤子开始，建成一座无人值守、能把矿石和庄稼变成吃的、穿的、用的东西的工厂。**

金属、基础化工、能源是支撑；食品、纺织、造纸、陶瓷玻璃、日化制药是主线。

```
搭产线 → 稳定产出 → 装箱交付（评级 / 订单）→ 解锁图纸 → 新产线与大机器 → 旧产线被合并或替代
```

- **工厂中枢与评级**：五个星级。每一级要求在一段时间内**持续**送入若干种装箱的产品，断供超过宽限时间就重新计时。
- **订单**：通过评级后开放的可重复目标。
- **终局**：五星评级 + 用整座工厂的产能打印一个「瓶中世界」。

## 2. 设计规则

以后加任何内容都先对照：

1. **交织**：每条线至少从两条别的线进料，至少给两条别的线供料。
2. **三条路线**：每种关键产品有「凑合 → 正规 → 高效」三种做法，后一种是换工艺。
3. **凑合路线不许卡死**：只依赖原版物品和上一阶段的产物，保证任何一条线都能独立起步。
4. **大机器合并产线**：每个阶段有多方块大机器，把一段小机器链合并成一台。
5. **对原版有用**：每条线至少一件产物在原版玩法里用得上。
6. **副产物有去处**：副产物槽满了停机；每种副产物都是别处的原料。
7. **不做惩罚性机制**：不做食物腐坏、机器爆炸、洁净室、十几级电压。

## 3. 数值基准

### 3.1 电力

现有发电：火力 10 EU/t，地热 20 EU/t。现有低压机器约 4 EU/t。以此为锚：

| 等级 | 单机耗电 | 典型设备 | 对应阶段 |
| --- | --- | --- | --- |
| LV 低压（≤32） | 2–8 EU/t | 小机器、传送带电机 | 0–2 |
| MV 中压（≤128） | 16–64 EU/t | 感应炉、电解机、选矿联合厂、发酵塔 | 1–3 |
| HV 高压（≤512） | 128–384 EU/t | 隧道窑、造纸机、灌装线、精馏塔 | 2–4 |
| EV 超高压（≤2048） | 512–2048 EU/t | 极光塔、发射场、微缩世界仪 | 4–5 |

全厂用电目标：一星约 60 EU/t，二星约 250，三星约 1 000，四星约 4 000，五星约 12 000。

**太阳能要重新平衡。** 现在六级太阳能是 1 / 8 / 64 / 512 / 4 096 / 32 768 EU/t，最高一级一台就超过五星全厂用电，电力设计会失去意义。计划改为 1 / 6 / 24 / 96 / 384 / 1 024，并保留「只在白天发电」。后期主力电源改为余热发电和裂变。

### 3.2 机器速度

以「件/分钟」为统一单位。

| 类型 | 速度 | 说明 |
| --- | --- | --- |
| 小机器（现有） | 6–15 件/分 | 单次加工 4–10 秒 |
| 小机器 + 4 个超频 | 约 3 倍 | 耗电约 5 倍 |
| 大机器（最小规格） | 小机器链的 4 倍 | 单件耗电为小机器链的 70% |
| 大机器（加长到上限） | 小机器链的 16 倍 | 单件耗电为 50% |
| 大机器 + 润滑油 | 再 ×1.25 | 每 1 000 次加工耗 1 桶润滑油 |

三种超频升级现在效果相同，要改成有区别：

| 升级 | 加工时间 | 耗电 |
| --- | --- | --- |
| 超频升级 | ×0.75 | ×1.5 |
| 高级超频升级 | ×0.60 | ×1.8 |
| 终极超频升级 | ×0.45 | ×2.2 |

高级款的优势是效率更好，而不只是更快。

| ★★ | 5 | 8 件/分 | 15 分钟 | 45 秒 | 小机器并联 + 传送带 |

## 4. 物流系统

目标：配置简单、后期极快、占用极低、看起来整洁、其他模组能用。

### 4.1 三层结构

| 层 | 设备 | 速度 | 耗电 | 阶段 |
| --- | --- | --- | --- | --- |
| 重力 | 滑槽 | 4 件/秒，只能向下或斜向下 | 无 | 1 |
| 带式 | 传送带 I / II / III | 4 / 16 / 64 件/秒 | 每 16 格 1 / 2 / 4 EU/t | 1 / 2 / 3 |
| 管网 | 气动管 + 物流接口 | 每个接口 64 件/秒，升级后 1 024 件/秒 | 每搬运 64 件 4 EU | 2–4 |
| 管廊 | 综合管廊 | 物品、流体、电力合一 | 同管网 | 5 |

参照：原版漏斗 2.5 件/秒；现有的弹出升级 1 件/秒。传送带 I 略快于漏斗，传送带 III 相当于每秒一组。

### 4.2 物流接口：配置方便的关键

接口是贴在机器某一面上的薄板，不占格子。三种模式：

- **自动（默认）**：接口读取所在机器的配方，自动向网络请求当前缺的原料，并把产物和副产物交给网络。贴上就能用，不用设置。
- **供应 / 请求**：手动指定物品和保有数量。
- **存储**：把箱子、料仓登记为网络的仓库。

其他配置手段：

- 过滤栏支持从 JEI 直接拖物品。
- **频道**用颜色区分，同一组管道里可以跑互不相干的几路。
- **配置器**工具：右键复制一个接口的设置，再右键粘贴到别的接口；潜行右键批量粘贴到相连的同类机器。
- 扳手右键管道的某一面断开连接（和现有导线一致）。

### 4.3 性能

沿用现在电力系统已经验证过的做法：

- **管道不逐个运算**。管网是一张缓存的图，只在放置、拆除时重建。
- **事件驱动**：接口没有待办时休眠，库存变化时才唤醒。
- **批量搬运**：每个网络每 4 tick 处理一次，有单次时间预算，超出顺延。
- **世界里不生成掉落物**。
- **传送带按「一条」运算而不是按格**：一段直线传送带是一个逻辑对象，物品是其中的位置数据。客户端只渲染玩家附近的物品，远处只显示带面滚动。
- **管道里的流动是动画**，由流量驱动，不模拟单件物品。

性能目标（用 Spark 实测验收）：2 000 格管道与传送带 + 300 个接口的工厂，物流占用服务器每 tick 不超过 0.5 毫秒。

### 4.4 美观

- 传送带上能看见物品在走；可以爬坡、转弯、上下层叠。
- 气动管有玻璃观察窗，能看到里面的流动；有直管、弯头、支架等外观件。
- 管道可以刷成频道颜色；可以埋进「线槽地板」里，表面只留一条盖板。
- 综合管廊把三种线路收进一个通道，后期工厂可以做到地面上看不到线。

### 4.5 给其他模组用

- 所有机器、接口、料仓都开放标准的物品和流体接口，漏斗和其他模组的管道可以直接接。
- 物流接口可以贴在其他模组的机器和容器上，按标准接口存取。
- 提供注册接口，让其他模组的方块声明自己是供应方或请求方。

### 4.6 流体

流体走同一套管网，用独立的流体管和流体接口；规则与物品一致。现有的「泵紧贴洗矿机供水」保留，作为最早期的凑合做法。

## 5. 大机器与多方块

### 5.1 规则

- 一台大机器等于一整段小机器链：原料进，成品出，中间产物不落地。
- 速度与耗电见 3.2。
- 造价跨线：外壳用耐火砖（陶瓷），传动用皮带（纺织），控制用电路板（金属），运行可加润滑油（日化）。
- 小机器不作废，是凑合路线。
- 可伸缩：隧道窑、造纸机、精馏塔等可以加长或加高，按长度线性提速，到上限为止。

### 5.2 框架

只写一套，所有大机器都是数据：

- **结构图样**：沿用指南已有的结构数据格式，增加「可重复段」和「可选方块」。
- **搭建投影**：手持图纸对准控制器，在世界里显示半透明投影；缺的方块标红，可以一键从背包补齐。
- **仓口**：物品仓、流体仓、能源仓、维护仓（放润滑油和模具）。物流接口可以直接贴在仓口上。
- **配方链**：一台大机器内部按顺序执行多条配方，支持并行数和副产物。
- **成型外观**：成型后整体换成专用模型，并有运行动画。

## 7. 其余主线

这几条线在各自阶段开始前再细化到配方级，这里定下方向和特色内容。

### 7.1 纺织服装（阶段 3）

- 工艺：梳理 → 纺纱 → 织布 → 印染 → 裁剪 → 缝制；生皮 → 鞣制。
- 三条路线（纤维）：羊毛与原版蛛丝 → 棉、麻 → 化学纤维。
- 特色内容：
  - 藕丝（缅甸茵莱湖）：从莲茎抽丝，产量极低，高档面料。
  - 菠萝叶纤维、蕉麻（菲律宾）：食品线的叶子边角料变成布。
  - 树皮布（太平洋诸岛）：不纺不织，直接捶打树皮成布，是纺织线的凑合路线。
  - 毛毡（蒙古）：羊毛加水加压，不用织机。
  - 蜡染（印度尼西亚）：蜂蜡画花再染色，得到带图案的布和旗帜。
  - 靛蓝发酵染：蓼蓝叶在染缸里发酵，需要食品线的发酵罐。
  - 胭脂红、骨螺紫：分别来自胭脂虫和海螺的稀有染料。
- 产物：工装、滤布、皮带、输送带、绝缘布、帆布、地毯、窗帘。

### 7.2 造纸印刷（阶段 3）

- 工艺：制浆 → 漂白 → 抄纸 → 压光；印刷；瓦楞与制箱。
- 三条路线：原版甘蔗纸 → 木浆造纸机 → 废纸回收。
- 特色内容：
  - 莎草纸（埃及）：茎切片交叠压制，凑合路线，不需要制浆。
  - 桑皮纸、和纸（东亚）：构树皮纤维，结实耐久，用于图纸。
  - 树皮纸（墨西哥）：石灰水煮树皮后捶打。
  - 羊皮纸：畜牧线的皮，用于高档书。
  - 松烟墨、铁胆墨水：前者是炭黑加胶，后者是橡树瘿加绿矾。
  - 活字印刷 → 轮转印刷：先做字模（金属线），再排版。
- 产物：纸箱、标签、滤纸、绝缘纸、图纸、书、地图。

### 7.3 陶瓷玻璃（阶段 2 做砖瓦瓶罐，阶段 4 做精细品）

- 工艺：练泥 → 成型 → 素烧 → 上釉 → 釉烧；熔制 → 吹制或浮法 → 退火。
- 三条路线：熔炉 → 间歇窑 → 隧道窑。
- 特色内容：
  - 骨瓷（英国）：坯料里加骨灰，需要畜牧线。
  - 锡釉陶（意大利马约利卡）：锡终于有了金属以外的用途。
  - 景泰蓝：铜丝掐花填釉，金属线与陶瓷线合作。
  - 乐烧（日本）：出窑后急冷，釉面每件都不同。
  - 铅晶质玻璃、硼硅玻璃：前者用铅，后者耐热，用作反应容器。
  - 铀玻璃：加少量铀，会微微发绿光，是装饰用的发光方块。
  - 千花玻璃（威尼斯）：彩色玻璃棒切片熔合。
  - 浮法玻璃：玻璃液浮在熔融的锡上摊平。
- 产物：耐火砖、瓷绝缘子、瓶罐、餐具、研磨球、光学玻璃、各色建材。

### 7.4 日化制药（阶段 4）

- 工艺：皂化；萃取与蒸馏；反应 → 结晶 → 压片或灌装。
- 三条路线（染料）：原版花草 → 萃取浓缩 → 合成染料。
- 特色内容：
  - 阿勒颇皂（叙利亚）：橄榄油加月桂油，窖藏熟成。
  - 非洲黑皂（西非）：用可可荚、果皮烧成的灰代替烧碱，是肥皂的凑合路线。
  - 无患子：果皮泡水就是洗涤剂，不需要任何加工。
  - 精油：蒸馏原版的花，得到香水和香薰。
  - 虫胶、生漆：分别来自紫胶虫和漆树，用于涂装和唱片。
  - 柳树皮 → 水杨酸 → 阿司匹林；金鸡纳树皮 → 奎宁；海带 → 碘酒。
- 产物：肥皂、洗涤剂、漂白剂、染料、颜料、润滑油、胶水、药片、肥料。

### 7.5 小线

- **烟花**：纸筒 + 火药 + 染料。原版刷怪塔的火药有了去处。
- **唱片**：虫胶压片，复制原版唱片。
- **家具**：木材 + 布料 + 胶水，做桌椅、沙发等装饰方块。

### 7.6 支撑线的调整

- **金属**：新增马口铁（镀锡钢板）、不锈钢（厨具、反应釜）、缝纫针、字模。
- **基础化工**：盐 → 烧碱 + 氯气；石灰石 → 石灰；纯碱；硫酸。只做轻工业需要的几样。
- **能源**：余热锅炉（窑炉废热 → 蒸汽 → 发电）、沼气（粪与厨余发酵 → 燃气）、裂变反应堆（中后期电源）。

## 10. 地标机器与终局

三台地标机器分布在中后期，各自有实际用处，同时是视觉上的里程碑。

### 10.1 天文钟楼（阶段 3）

- 结构：5×13×5 的塔，需要齿轮（金属）、钟面玻璃（陶瓷）、皮带（纺织）。
- 用处：
  - **排班**：设定班次表，范围内的机器按游戏时间自动启停。夜间停掉不必要的线可以省电。
  - 输出红石定时信号。
  - 整点报时；可以装入「乐谱卷」演奏音符盒乐曲。
- 耗电：16 EU/t。

### 10.2 极光塔（阶段 4）

- 结构：7×21×7 的电离塔，需要瓷绝缘子、铜线圈、光学玻璃。
- 用处：
  - 半径 48 格内，种植机和露天作物夜间按白天速度生长。
  - 范围内不生成敌对生物。
  - 夜晚塔顶上空出现极光。
- 耗电：512 EU/t，只在夜间工作。

### 10.3 卫星发射场（阶段 5）

- 结构：11×11 的发射台和塔架。每次发射消耗一枚火箭（金属 + 燃料 + 防热瓦）和一颗卫星。
- 三种卫星：
  - **通信卫星**：解锁远程交付终端，在任何地方（含其他维度）向中枢交付和查看工厂状态。
  - **气象卫星**：提前显示未来的天气；可以耗电指定一次天气。
  - **资源卫星**：扫描指定区块，列出矿物分布。
- 卫星可以命名；发射后夜空里多一个移动的亮点。

### 10.4 裂变反应堆（阶段 4）

保留，定位是高压到超高压阶段的主力电源之一。设计重点是燃料循环（燃料棒 → 乏燃料 → 后处理回收），不做爆炸。

### 10.5 终局：微缩世界仪与瓶中世界

- 结构：9×9×9。需要全部六条主线的高级产物。
- 用法：用测绘仪框选一块区域（最大 48×48×48），机器逐层扫描并打印。
- 消耗：每一层都要光学玻璃、显影树脂、颜料、精密部件、衬布和底座木料，由物流持续供给。按五星工厂的产能，打印一个最大规格的作品约需 3 小时游戏时间。断供只暂停，不清零。
- 耗电：2 048 EU/t。
- 产物：**瓶中世界**。一个可以放置的玻璃球，里面是那块区域的立体微缩模型，缓慢旋转；可以署名、送人、摆在展示架上。它对产线没有任何用处。
- 可以重复打印不同区域，小规格更快。

## 12. 分阶段计划

每个阶段结束时模组都完整可玩，并且可以单独发布。

### 阶段 0：地基

没有新玩法，玩家几乎看不出变化。

1. 把生成、校验脚本整理入库，接入构建。
2. 给现有每台机器补回归测试（加工、存档、升级、供电）。
3. 机器基类；逐台迁移现有机器，行为不变。
4. 扩展配方类型：多输入、多输出、流体、催化物。
5. 流体系统；洗矿机、电解机、泵、地热发电机改用真正的流体。
6. 所有机器开放物品与流体接口。
7. 补齐掉落表；文本本地化；删除旧网络代码；JEI 改用同步配方。
8. 重新平衡：太阳能输出、三种超频升级。

验收：全部回归测试通过；漏斗能给机器进出料；镐挖机器会掉落；新增一台简单机器不超过 100 行。

### 阶段 1：核心循环与第一台大机器

1. 工厂中枢；一星、二星评级；评级界面与指南章节。
2. 欠压降速；副产物堵塞。
3. 模具系统，替换金属成型机的模式按钮。
4. 物流第一层：滑槽、传送带 I、物流接口（自动模式）、配置器。
5. 多方块框架；选矿联合厂；搭建投影。
6. 电动修理台、电灯。

验收：只靠自动化能拿到二星；选矿联合厂的速度是小机器链的 4 倍；物流性能达到 4.3 的目标。

**这是决策点**：评级玩法是否好玩、多方块框架与物流内核是否稳。任何一项不成立，先修正再往下。

### 阶段 2：吃

1. 首批作物 8 种（水稻、大豆、玉米、木薯、辣椒、茶树、苔麸、枫树）及野生分布。
2. 食品机器 9 种（见 6.2）与菌种系统。
3. 首批食品：基础食品，以及特色食品 8 种。
4. 畜牧：喂食槽、挤奶机、剪毛机、集蛋器、孵化机、屠宰台；饲料三档；黑水虻。
5. 陶瓷玻璃前半：粘土、耐火砖、瓶罐、发酵缸、间歇窑。
6. 大机器：隧道窑与隧道烤炉、发酵塔、联合畜舍。
7. 物流第二层：传送带 II、气动管网、流体管。
8. 装箱机与草编筐；三星评级。
9. 食堂、建材机、冷冻机。
10. 其余作物 8 种与剩下的特色食品。

验收：三星评级可达成；每种特色食品都有完整的自动化产线；副产物全部有去处，没有会永久堵死的环节。

### 阶段 3：穿与用

1. 纺织服装线，纺织联合车间，工装。
2. 造纸印刷线，长网造纸机，纸箱替换草编筐。
3. 订单板与工厂点数。
4. 传送带 III；管网接口升级。
5. 天文钟楼。
6. 打包箱、印刷机。
7. 瓶中世界的渲染原型（只做技术验证，不上线）。

验收：订单可以持续运转；纸箱成为交付的标准包装；瓶中世界原型确认可行或确定降级方案。

### 阶段 4：精细

1. 日化制药线，精馏塔。
2. 陶瓷玻璃后半：骨瓷、光学玻璃、特种玻璃。
3. 灌装流水线；马口铁罐头。
4. 余热发电、沼气、裂变反应堆。

## 13. 风险与待验证

| 项 | 风险 | 应对 |
| --- | --- | --- |
| 范围 | 是现有内容的十倍以上 | 严格按阶段推进；每阶段可单独发布 |
| 瓶中世界的渲染 | 把大片区域缩小渲染，效果和性能未验证 | 阶段 3 做原型；退路是降低分辨率或静态快照 |
| 传送带的显示 | 大量可见物品可能拖慢客户端 | 只渲染附近；远处只显示带面动画 |
| 物流性能目标 | 0.5 毫秒是目标，未实测 | 阶段 1 先做内核并实测，不达标先优化再加功能 |
| 多方块 | 结构校验、区块边界、可伸缩规格都容易出错 | 先做最简单的选矿联合厂；每台配整线测试 |
| 评级玩法 | 没有现成先例，速率统计和断供判定要试 | 阶段 1 用现有产品做最小版本 |
| 交织过头 | 六条线互相依赖，开局容易卡死 | 规则 3：每条线的凑合路线只依赖原版和上一阶段 |
| 对原版过强 | 酿造车间、修理台、打包箱、工装可能破坏平衡 | 每件都定明确代价；上线前逐个评估 |
| 地基重构 | 会改动所有现有机器 | 先补测试再重构；保证旧存档不丢东西 |
| 美术 | 作物、食品、机器、大机器模型数量很大 | 用脚本批量生成基础贴图；大机器成型模型逐个手工做 |
| 动物数量 | 畜牧容易造成卡顿 | 畜舍按面积限制数量 |

第 3 节的所有数值、各线的具体配方，都要在对应阶段开始前再做一轮细化。
