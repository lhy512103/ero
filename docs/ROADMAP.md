# IUCE 开发计划

> 状态：草案，待确认。第 8 节列出了需要先拍板的几个选择，其余内容都建立在这些选择之上。

## 1. 现状

| 项目 | 现状 |
| --- | --- |
| 内容量 | 约 130 个物品、约 70 个方块、286 条配方、13 种加工/发电/储能机器 |
| 流程长度 | 手工 → 低压 → 合金 → 电解 → 太阳能阶梯，熟手几小时走完 |
| 电压 | 绝大多数机器是低压；中压以上只有感应炉、电解机和储能/太阳能 |
| 终点 | 奇异太阳能。它只是「更多的电」，而电没有更大的用处 |
| 半成品 | 裂变反应堆只有方块和配方，不能运行；三种超频升级效果相同 |

问题不在机器数量，而在三件事：

1. **没有目的。** 产线造出来的东西只用来造下一台机器，最后一台机器造完就没事做了。
2. **产线不需要「一直转」。** 几乎所有东西都是「做一次就够」，搭自动化的回报很低。
3. **每条线只有一种做法。** 没有「先凑合、再升级、最后换路线」的空间。

## 2. 定位：建一座黑灯工厂

**一句话：从一把锤子开始，建成一座不需要人看管、能持续交付的工厂。**

「黑灯工厂」是现实里的说法：全自动、无人值守，所以不用开灯。它给模组一个明确的方向，并且和格雷科技、原版工业升级拉开了区别：

| | 格雷 / 传统科技模组 | IUCE |
| --- | --- | --- |
| 衡量进度的方式 | 合成出某件物品 | 工厂能**持续**以某个速率产出 |
| 难点 | 配方树深 | 把产线调到稳定：供料、供电、副产物都不堵 |
| 终点 | 最终物品 / 最高电压 | 工厂通过最高等级的无人值守认证 |

这一条决定了后面所有设计：**凡是「做一次就够」的设计尽量少加，凡是让产线必须持续运转、并且值得优化的设计优先加。**

## 3. 核心循环

```
搭产线 → 稳定产出 → 交付（认证 / 订单）→ 获得图纸与评级 → 解锁新工艺 → 旧产线有了更好的做法 → 改造
```

### 3.1 工厂中枢与评级（主线目标）

一个放在基地里的方块，对应五个评级。每一级要求**在一段时间内持续送入**指定的几种产品：

- 例：一星要求 10 分钟内持续送入铁板、铜导线、橡胶，速率不低于每分钟若干个。
- 断供超过宽限时间，计时重来。手搓赶不上，只能靠自动化。
- 通过后解锁下一阶段的图纸（配方）。评级越高，要求的产品越复杂、种类越多。

它取代「合成最终物品」成为终局：五星评级就是一座完整的黑灯工厂。

### 3.2 订单（可重复的目标）

通过评级后开放订单板：随机给出「某产品 × 数量」，交付后得到点数，用来换装饰方块、稀有材料或额外的升级槽位。订单让后期一直有事做，也给过剩产能一个出口。

### 3.3 每种关键材料三条路线

每个阶段的关键材料都按「凑合 → 正规 → 高效」设计，后一条路线不是单纯更快，而是**换一种做法**，并带来新的副产物或新的需求：

| 材料 | 凑合 | 正规 | 高效 |
| --- | --- | --- | --- |
| 钢 | 感应炉 + 煤球（现有） | 高炉炼生铁 → 转炉吹氧 | 电弧炉回收废钢 |
| 铝 | 电解粘土（现有） | 铝土矿 + 烧碱 → 氧化铝 → 电解 | 加冰晶石与碳阳极，耗电减半 |
| 铜 | 打粉 + 电炉（现有） | 火法粗铜 → 电解精炼 | 阳极泥里回收金、银 |
| 橡胶 | 树液（现有） | 加硫硫化，产量翻倍 | 合成橡胶 |
| 玻璃 | 熔炉 | 浮法玻璃（玻璃液浮在熔融锡上） | 镀膜 → 太阳能玻璃 |

这些都取自真实工艺，自带「为什么要多一步」的理由，不用硬编。

## 4. 让产线有意思的机制

下面是候选机制。**不建议全做**，建议先做前三个，它们和「持续运转」的定位最贴。

### 4.1 副产物必须有去处 ★建议优先

现实里工厂最头疼的不是主产品，而是废渣、废水、废气。

- 机器的副产物槽满了就停机。副产物不是奖励，是要处理的东西。
- 每种副产物都有用处：高炉渣 → 水泥；洗矿尾矿 → 再选出稀有金属；阳极泥 → 金银；废热 → 发电。
- 结果：一条线搭完后，会自然长出第二、第三条线。这就是「套娃」，但每一层都有现实依据，而不是凭空多一个中间件。

### 4.2 欠压降速 ★建议优先

现在电不够机器就停。改成：供电不足时机器按比例减速。

- 电网带不动时全厂一起变慢，而不是随机停几台。玩家能直观看到「该扩电了」。
- 让储电箱有了削峰填谷的意义，也让变压器和导线的吞吐成为真正的设计问题。
- 实现量小，但对「调产线」的体验影响很大。

### 4.3 模具与工装 ★建议优先

金属成型机现在用按钮切换三种模式。改成放入**模具**决定产出：板模、线模、棍模，以及后续的齿轮模、管模、壳体模。

- 加新零件只要加一个模具物品和一条配方，不用改机器。
- 模具本身是一条小产线（钢 → 模具钢 → 模具），高级模具更耐用或一次出更多。
- 可以推广：注塑机用模腔、冲压机用冲头。

### 4.4 热量与余热

冶金类机器产生热量，热量是第二种「能量」：

- 高炉、感应炉工作时向相邻方块放热。
- 余热锅炉把热变成蒸汽，蒸汽推汽轮机发电，或直接供给需要加热的机器（省电）。
- 现有「感应炉给相邻电炉加速」可以改写成这套机制的一个特例。

这是工作量最大的一项，但它能把发电、冶金、化工三块连成一个整体。

### 4.5 流水线工位

取自汽车总装线：产品在一条线上依次经过多个工位，每个工位装一个零件。

- 一排「工位」方块连成线，半成品从一端进、成品从另一端出。
- 整线速度取决于最慢的工位；可以给慢工位并联。
- 用于最复杂的产品（高级电路板、电机、电池组），替代「在工作台里摆九宫格」。

这是和现有科技模组差异最大的一项，适合放在中后期作为亮点。

### 4.6 不建议做的

- **洁净室、电压一路堆到十几级**：格雷的标志性设计，照搬只会变成缩水版格雷。
- **自己做一整套管道 / 传送带**：工作量极大，而且别的模组做得更好。建议只把物品和流体接口开放出来，让漏斗和其他模组的管道能接；自己只做最小限度的近距离传输。
- **机器损坏、爆炸惩罚**：和「调产线」的乐趣无关，只增加挫败感。变压器漏电这种「有警示、可规避」的危险可以保留。

## 5. 产线蓝图

按主题分四条大线，每条线内部都遵循 3.3 的三条路线。

### 5.1 冶金（钢铁厂）

```
铁矿 → 烧结 → 高炉（+焦炭、石灰石）→ 生铁 → 转炉（+氧气）→ 钢 → 连铸 → 轧制
                 └ 高炉渣 → 水泥        └ 钢渣 → 回炉       └ 废热 → 余热锅炉
```

新内容：焦炉（煤 → 焦炭 + 煤焦油 + 煤气）、高炉（多方块）、转炉、空气分离（制氧）、石灰石与铁矿。

### 5.2 化工（氯碱与化肥）

```
盐水 → 电解 → 氯气 + 氢气 + 烧碱
               │      │      └ 铝土矿提纯（铝线）
               │      └ 合成氨 → 化肥 → 种植机增产
               └ 聚氯乙烯 → 绝缘导线的替代材料
```

电解机从「几条零散配方」变成一条线的核心。化肥把种植机接进了主线：种植不再是支线，而是橡胶和生物原料的来源。

### 5.3 电子（硅与芯片）

```
石英 + 碳 → 工业硅 → 提纯 → 拉晶 → 切片 → 光刻 → 芯片 → 流水线装配 → 电路板
                                    └ 边角料 → 太阳能电池片
```

替换现在的「导线 + 红石 + 铁板 = 电路板」。太阳能阶梯改为由电池片产线支撑，而不是「两台低级合成一台高级」。

### 5.4 能源

| 阶段 | 来源 | 特点 |
| --- | --- | --- |
| 早期 | 火力、地热（现有） | 烧燃料 |
| 中期 | 余热锅炉 + 汽轮机、煤气发电 | 吃副产物，鼓励把冶金线做大 |
| 中后期 | 太阳能（改造后） | 需要电子线支撑 |
| 后期 | 裂变反应堆（补完） | 需要冷却、燃料后处理，产出高放废料要处理 |

反应堆的设计重点放在「燃料循环」而不是「防爆炸」：铀 → 燃料棒 → 乏燃料 → 后处理回收一部分。

## 6. 先要补的地基

下面这些不是新玩法，但不做的话后面每加一条线都会越来越慢。

| 项 | 现状 | 为什么要先做 |
| --- | --- | --- |
| 机器基类 | 每台机器各写一遍槽位、进度、存档，单机 300–700 行 | 加一台机器要复制几百行；新机制（欠压、副产物堵塞）得改十几处 |
| 流体 | 只有一个整数表示「水量」，没有真正的流体种类 | 化工、冶金、余热全都要多种流体 |
| 对外接口 | 机器没有开放物品 / 流体接口，漏斗和别的模组的管道接不上 | 不开放就必须自己做整套物流 |
| 方块掉落 | 没有任何掉落表，机器用镐挖掉什么都不掉 | 基础体验问题 |
| 文本 | 机器名、提示有 60 多处写死中文 | 做不了英文版 |
| 旧代码 | 旧的能量网络、物流、负载均衡约 1400 行，已基本不被调用 | 容易误导，改电力时要绕着走 |
| 多人游戏 | JEI 配方页依赖单人游戏的内置服务器 | 开服后配方页是空的 |
| 配方生成 | 生成配方、校验配方图的脚本不在仓库里 | 加几百条配方必须靠脚本，且要可重复运行 |
| 测试 | 16 项回归测试，覆盖电力、扳手、种植、变压器、升级 | 每条新线需要「整条线跑通」的测试 |
| 多方块 | 没有结构校验框架；指南里已有结构数据格式 | 高炉、反应堆、流水线都要用 |

## 7. 分阶段计划

规模只标相对大小（小 / 中 / 大），不承诺时间。每个阶段结束时模组都应该是完整可玩的。

### 阶段 0：地基（大）

- 机器基类重构，现有机器迁移过去，行为不变（回归测试兜底）。
- 真正的流体系统；开放物品 / 流体接口。
- 掉落表、文本本地化、删除旧网络代码、JEI 多人支持。
- 配方生成与校验脚本入库。
- 修掉已知半成品：三种超频升级做出区别。

验收：玩家看不出变化，但加一台新机器不超过 100 行代码。

### 阶段 1：核心循环最小版（中）

- 工厂中枢 + 一星、二星评级（只用现有产品）。
- 欠压降速。
- 副产物堵塞规则，先套在洗矿机上。
- 模具系统替换金属成型机的模式按钮。
- 指南补「工厂评级」章节。

验收：现有内容不变的情况下，玩家第一次有了「让产线一直转」的理由。**这一阶段做完就能判断定位对不对，不对可以及时调头。**

### 阶段 2：冶金线（大）

- 多方块框架 + 高炉、焦炉、转炉、空气分离。
- 热量与余热（如果第 8 节选择做）。
- 钢的三条路线；高炉渣 → 水泥 → 建筑方块。
- 三星评级。

### 阶段 3：化工线（大）

- 氯碱电解、合成氨、化肥；铝的三条路线；橡胶硫化与合成。
- 种植机接入化肥。
- 订单板。

### 阶段 4：电子线（大）

- 硅 → 芯片；流水线工位；电路板改由流水线生产。
- 太阳能阶梯重做。
- 四星评级。

### 阶段 5：能源与终局（大）

- 裂变反应堆补完，燃料循环。
- 五星评级：全线无人值守运行。
- 终局后的订单与装饰内容。

### 可以随时插入的小项

- 更多机器等级（中压、高压版本的打粉机等，更快、多槽位）。
- 更多装饰与建筑方块（工厂地板、警示条纹、管廊）。
- 英文指南。

## 8. 需要先确认的选择

1. **终局形式。** 方案见 3.1 / 3.2。
   - A（建议）：工厂评级为主线，订单为重复目标。
   - B：只做订单经济，没有固定终点。
   - C：传统路线，做一个最终大工程（需要海量物资分阶段交付）。

2. **热量系统做不做。** 做的话冶金、发电、化工能连成一体，但它是单项工作量最大的机制，并且要重写感应炉与电炉的联动。不做的话，余热简化成「机器额外产出蒸汽」这一种副产物。

3. **物流自己做多少。**
   - A（建议）：开放接口给漏斗和其他模组，自己只保留现有的升级式近距离传输。
   - B：自己做传送带 / 管道，体验统一但工作量翻倍。

4. **现有配方动不动。** 5.3 会替换电路板和太阳能阶梯的做法，旧存档里的产线会失效。可以接受的话直接替换；不能接受就保留旧配方作为「凑合」路线。

5. **难度取向。** 评级的速率要求定多高，决定了模组是「休闲搭线」还是「需要算产能」。建议先定得宽松，靠高星级拉难度。

## 9. 风险

- **范围。** 这份计划是现有内容的数倍。阶段 0 和阶段 1 是无论如何都值得做的；阶段 2 之后应当在阶段 1 验证过定位之后再展开。
- **评级机制没有先例可抄。** 速率怎么测、断供怎么算、多人怎么共享，都要在阶段 1 用最小版本试出来。
- **地基重构会碰所有机器。** 必须先把回归测试补到每台机器都有覆盖，再动手。
- **内容量靠脚本。** 几百条配方手写不现实；生成脚本、配方图校验、指南页面要成套维护。
