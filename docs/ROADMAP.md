# IUCE 开发计划

> 状态：草案第 2 版，待确认。第 12 节是需要先拍板的选择。
> 相比第 1 版：主线从重工业改为轻工业；每个阶段加入大型多方块机器；补充面向原版玩法的设备；裂变反应堆不再是终局；产线之间强制交织。

## 1. 现状与问题

| 项目 | 现状 |
| --- | --- |
| 内容量 | 约 130 个物品、约 70 个方块、286 条配方、13 种机器 |
| 流程 | 手工 → 低压 → 合金 → 电解 → 太阳能阶梯，熟手几小时走完 |
| 终点 | 奇异太阳能，只是「更多的电」，而电没有更大的用处 |
| 多方块 | 没有。裂变反应堆只有方块和配方，不能运行 |
| 和原版的关系 | 除了电炉能烧原版配方、种植机能种原版作物，模组产物只在模组内部消化 |

归纳成四个问题：

1. **没有目的。** 产线造的东西只用来造下一台机器。
2. **产线不需要一直转。** 几乎所有东西「做一次就够」。
3. **每条线只有一种做法，线和线之间没有关系。**
4. **对原版没用。** 不装这个模组的玩法里，看不到它的好处。

## 2. 定位：造日用品的黑灯工厂

**一句话：从一把锤子开始，建成一座无人值守、能把矿石和庄稼变成吃的、穿的、用的东西的工厂。**

多数科技模组停在「炼出金属、做出芯片」。IUCE 往后多走一段：金属、化工、能源是**供应**，不是目的；目的是罐头、衣服、书、瓷器、药品这些终端产品。

这个方向同时解决了上面的问题 3 和 4：

- 轻工业天然互相依赖。罐头要马口铁、标签和纸箱；衣服要染料和纽扣；造纸要烧碱和滤布。
- 终端产品天然对原版有用。食物、衣服、书、药水本来就是原版玩法的一部分。

衡量进度的方式仍然是第 1 版的结论：**不看「合成出了什么」，看「工厂能持续以多快的速率产出」。**

## 3. 核心循环

```
搭产线 → 稳定产出 → 装箱交付（评级 / 订单）→ 解锁图纸 → 新产线、大机器 → 旧产线被合并或替代
```

- **工厂评级（主线）。** 工厂中枢方块，五个星级。每一级要求在一段时间内持续送入若干种**装箱的**终端产品，断供超时就重新计时。手搓赶不上。
- **订单（重复目标）。** 评级后开放。交付得到点数或绿宝石，换装饰、稀有材料、额外升级槽。
- **装箱。** 交付的产品必须用纸箱包装。这一条让造纸线成为所有线的公共出口，是最简单的交织手段。

## 4. 五条设计规则

以后加任何内容，先对照这五条：

1. **交织。** 每条线至少从两条别的线进料，至少给两条别的线供料。没有一条线能单独做完。
2. **三条路线。** 每种关键产品有「凑合 → 正规 → 高效」三种做法，后一种是换工艺，不是单纯提速。
3. **大机器合并产线。** 每个阶段有一台多方块大机器，把上一阶段的一整段小机器链合并成一台。
4. **对原版有用。** 每条线至少有一件产物在原版玩法里用得上。
5. **副产物要有去处。** 副产物槽满了就停机；每种副产物都是另一条线的原料。

## 5. 产线

金属、基础化工、能源是三条**支撑线**，现有内容大部分属于这里，不再展开成主线。下面是六条**主线**。

### 5.1 食品

```
谷物 → 磨粉 → 和面 → 发酵 → 烘烤 → 面包、饼干
油料 → 压榨 → 精炼 → 食用油          甘蔗 / 甜菜 → 榨汁 → 熬糖
肉、菜、果 → 蒸煮 → 装罐 → 杀菌 → 罐头
```

- 三条路线（保存方式）：现做现吃 → 玻璃瓶罐装 → 马口铁罐头流水线。
- 进料：马口铁罐（金属，锡终于有大用处）、玻璃瓶（陶瓷玻璃）、标签与纸箱（造纸）、滤布（纺织）、盐与小苏打（基础化工）、奶蛋肉（畜牧）。
- 副产物：麸皮、豆粕、酒糟 → 饲料；废油 → 肥皂；淀粉 → 纺织上浆、纸张施胶。
- 给原版：可堆叠、饱和度高的罐头和便当；带短时增益的工作餐；食堂方块给周围玩家持续增益。

### 5.2 畜牧养殖

```
饲料 → 畜舍（牛、羊、鸡、猪）→ 奶、蛋、毛、肉、皮、骨、粪
```

- 三条路线：原版放养 → 自动喂食、挤奶、剪毛的畜舍 → 配方饲料提高产量。
- 进料：饲料（食品副产物）、药品（日化制药）、垫料（造纸、纺织边角料）。
- 副产物：骨 → 骨瓷和明胶；粪 → 肥料 → 种植机；油脂 → 肥皂。
- 给原版：自动挤奶、剪毛、收蛋、孵化，直接替代手动养殖。

### 5.3 纺织服装

```
棉、麻、羊毛、蛛丝 → 梳理 → 纺纱 → 织布 → 印染 → 裁剪 → 缝制
生皮 → 鞣制 → 皮革
```

- 三条路线（纤维来源）：羊毛和原版蛛丝 → 种植棉麻 → 化学纤维。
- 进料：染料、漂白剂、洗涤剂（日化）；缝纫针、纽扣、拉链（金属）；淀粉浆料（食品）。
- 供料：滤布（洗矿、食品、化工）、传动皮带与输送带（所有大机器）、绝缘布（电机、变压器）、碎布（造纸）。
- 给原版：工装。矿工服、绝缘服（免疫变压器电击）、防火服、厨师服，穿戴后有对应效果；批量染色的羊毛、地毯、旗帜、床。

原版刷怪塔产出的蛛丝在这里是正经原料，原版农场和模组产线第一次接上了。

### 5.4 造纸印刷

```
木材、碎布、甘蔗渣 → 制浆（烧碱）→ 漂白 → 抄纸 → 压光
纸 + 油墨 → 印刷 → 书、标签、图纸      纸 → 瓦楞 → 纸箱
```

- 三条路线：原版甘蔗造纸 → 木浆造纸机 → 废纸回收再造。
- 进料：烧碱、漂白剂、胶水（化工、日化）；滤布（纺织）；炭黑油墨（基础化工）。
- 供料：纸箱（所有线的交付出口）、标签（食品、制药）、滤纸（制药）、绝缘纸（变压器）、图纸（解锁配方）。
- 给原版：批量的纸和书；印刷机复制成书、地图、旗帜图案；**打包箱**，把一个箱子的内容装成一件物品带走。

### 5.5 陶瓷玻璃

```
粘土、高岭土 → 练泥 → 成型 → 素烧 → 上釉 → 釉烧
石英砂 + 纯碱 → 熔制 → 吹制 / 浮法 → 退火
```

- 三条路线：原版熔炉烧砖 → 间歇窑 → 连续的隧道窑。
- 进料：纯碱（基础化工）、釉料与颜料（日化）、骨灰（畜牧）、燃料或电（能源）。
- 供料：耐火砖（所有窑炉和大机器的外壳）、瓷绝缘子（高压设备）、瓶罐（食品、制药）、研磨球（磨机）、光学玻璃（终局）。
- 给原版：批量的砖、陶瓦、带釉陶瓦、各色玻璃；餐具和花瓶等装饰。

### 5.6 日化制药

```
油脂 + 烧碱 → 皂化 → 肥皂、洗涤剂      植物、矿物 → 萃取 → 染料、颜料
原料药 → 反应 → 结晶 → 压片 / 灌装 → 药品
```

- 三条路线（染料）：原版花草染料 → 萃取浓缩 → 合成染料。
- 进料：油脂（食品、畜牧）、酒精与糖（食品）、玻璃瓶（陶瓷玻璃）、滤纸与标签（造纸）、明胶胶囊（畜牧）。
- 供料：染料与漂白剂（纺织、造纸）、润滑油（大机器的消耗品，加了提速）、胶水（造纸）、肥料与农药（种植机）。
- 给原版：成批酿造药水的酿造车间；可堆叠的药片（效果等同药水）；批量染料。

### 5.7 备选小线

内容少、趣味强，可以在任意阶段插入：

- **烟花**：纸筒 + 火药 + 染料 → 烟花火箭。鞘翅玩家的刚需，原版刷怪塔的火药有了去处。
- **唱片**：虫胶或塑料 + 压片机 → 复制原版唱片。
- **家具**：木材 + 布料 + 胶水 → 桌椅、沙发、窗帘等装饰方块。

## 7. 大机器与多方块

### 7.1 原则

- **一台大机器 = 一整段小机器链。** 例如「选矿联合厂」等于打粉机 + 洗矿机 + 电炉：矿石进，锭出。
- **目标**：处理速度约为小机器链的 4–8 倍，占地更小，单件耗电更低。具体数值到实装时再平衡。
- **造价跨线。** 外壳用耐火砖（陶瓷）、传动用皮带（纺织）、控制用电路板（金属与电子）、运行要润滑油（日化）。大机器本身就是交织的体现。
- **小机器不作废。** 小机器是「凑合」路线，大机器是「高效」路线，中间可以混用。
- **能伸缩。** 部分大机器的长度或高度可以加长，越长越快或越纯。一套框架因此能做出很多规格。

### 7.2 每个阶段的旗舰机器

| 阶段 | 大机器 | 合并的环节 | 取自 |
| --- | --- | --- | --- |
| 1 | 选矿联合厂（固定 3×3×3） | 打粉 → 洗矿 → 熔炼 | 选矿厂 |
| 2 | 隧道窑（长度可加长） | 素烧 → 上釉 → 釉烧；换成烤炉内胆即为面包隧道烤炉 | 陶瓷厂、饼干厂的隧道窑 |
| 3 | 长网造纸机（长度可加长） | 制浆 → 抄纸 → 烘干 → 压光 | 真实造纸机长达百米 |
| 3 | 纺织联合车间 | 梳理 → 纺纱 → 织布 | 纺织厂 |
| 4 | 精馏塔（高度可加高） | 多次蒸馏提纯 | 化工厂 |
| 4 | 灌装流水线 | 装罐 → 封口 → 杀菌 → 贴标 → 装箱 | 罐头厂、饮料厂 |
| 5 | 终局机器 | 见第 9 节 | — |

### 7.3 为什么难，以及怎么降低风险

难点是确实存在的，按影响排序：

1. **结构校验。** 要处理区块未加载、结构被部分拆除、朝向与镜像、可伸缩长度。
2. **仓口。** 物品、流体、能量从哪些方块进出，多个仓口如何分配。
3. **运行逻辑。** 一台机器内部跑一条链，中间产物、副产物、并行数量都要算。
4. **显示。** 成型后的外观、运行动画、指南里的搭建指引。

降低风险的办法：

- **只写一套框架**：结构图样 + 仓口 + 配方链，所有大机器都是数据。指南已有的结构数据格式（`guide/structures/*.json`）直接作为结构图样的来源，搭建时用它做世界内投影。
- **先做最简单的一台**：阶段 1 的选矿联合厂是固定尺寸、单链、无流体。它跑通之后再做可伸缩的。
- **每台大机器配一个整线测试**：结构成型、缺一块失效、整链产出正确。

## 8. 给原版用的设备

目标：只玩原版内容的人，也愿意为了这些东西装模组。

| 设备 | 作用 | 所属线 |
| --- | --- | --- |
| 自动畜舍 | 喂食、挤奶、剪毛、收蛋、孵化 | 畜牧 |
| 酿造车间 | 成批酿造药水，一次多瓶 | 日化制药 |
| 打包箱 | 把一个容器的内容装成一件物品，放下后还原 | 造纸 |
| 印刷机 | 复制成书、地图、旗帜图案 | 造纸 |
| 调色机 | 给羊毛、玻璃、陶瓦、混凝土整批换色 | 日化 |
| 建材机 | 混凝土粉直接出混凝土；石材批量切台阶、楼梯 | 陶瓷玻璃 |
| 烟花机 | 批量做烟花火箭 | 备选小线 |
| 电动修理台 | 用电修复工具和盔甲的耐久 | 金属 |
| 食堂 | 放入工作餐，给周围玩家持续增益 | 食品 |
| 工装 | 矿工服、绝缘服、防火服等带效果的服装 | 纺织 |
| 电灯 | 用电的高亮度照明与路灯 | 支撑 |

反方向也要接上：原版农场的产物是模组产线的原料。蛛丝 → 纺织，火药 → 烟花，骨头 → 骨瓷与肥料，腐肉 → 饲料。

订单可以用绿宝石结算，让工厂的产出进入原版的村民交易。这一项会影响原版经济，列在第 12 节待定。

## 9. 终局

裂变反应堆保留，定位改为**中后期的一种发电方式**，与余热发电、太阳能并列，不再是终点。

终局机器的要求：规模最大、需要所有线同时供料、产物**对产线没有用处**，但新奇、值得展示。

### 9.1 建议方案：微缩世界仪 → 瓶中世界

一台大型多方块机器。玩家框选世界里的一块区域（例如自己的工厂），机器把它一层一层「打印」成一个玻璃球里的微缩模型。

- 成品「瓶中世界」是一件可以放置的物品：玻璃球里是那块区域的立体微缩景观，缓慢旋转。可以送人。
- 打印过程持续很久，全程消耗各条线的产品：光学玻璃（陶瓷玻璃）、颜料与树脂（日化）、精密部件（金属）、包装底座（造纸、纺织）。断供只会暂停，不会清零。
- 它符合模组的主题：终局不是更大的数字，而是把你亲手建的工厂做成一件纪念品。

**可行性未验证。** 把一块区域缩小后在玻璃球里渲染出来，需要先做原型确认性能和效果。退路是降低分辨率，或只保存一张静态快照。

### 9.2 备选方案

- **命名卫星**：发射场把一颗以玩家命名的卫星送上天，之后夜空里多一颗会移动的亮点。
- **极光塔**：建成后基地上空的夜晚出现极光。纯景观。
- **天文钟楼**：巨型机械钟，按游戏时间报时，并能自动演奏玩家编排的音符盒乐曲。

## 10. 机制

沿用第 1 版里建议优先的三项，都和「持续运转」直接相关：

- **副产物堵塞。** 副产物槽满了就停机。
- **欠压降速。** 供电不足时机器按比例减速，而不是直接停。
- **模具。** 金属成型机改为放入模具决定产出；以后推广到注塑、冲压、压片。

热量与余热系统降级为可选项：窑炉先只区分「烧燃料」和「用电」两种，余热作为一种副产物（蒸汽）处理。是否做成完整的热量系统见第 12 节。

明确不做：洁净室、十几级电压、机器爆炸惩罚、自己的整套传送带与管道。

## 11. 地基

这些不是新玩法，但不做的话后面每条线都会越来越慢。

| 项 | 现状 | 为什么要先做 |
| --- | --- | --- |
| 机器基类 | 每台机器各写一遍槽位、进度、存档，单机 300–700 行 | 新机制要改十几处；大机器的配方链要复用同一套逻辑 |
| 多方块框架 | 没有 | 每个阶段都要用 |
| 流体 | 只有一个表示「水量」的整数 | 食品、化工、造纸全都要多种流体 |
| 对外接口 | 漏斗和别的模组的管道接不上机器 | 不开放就必须自己做整套物流 |
| 方块掉落 | 没有任何掉落表 | 基础体验问题 |
| 文本 | 60 多处写死中文 | 做不了英文版 |
| 旧代码 | 旧的能量网络、物流、负载均衡约 1400 行，基本不被调用 | 容易误导 |
| 多人游戏 | JEI 配方页依赖单人游戏的内置服务器 | 开服后配方页是空的 |
| 配方脚本 | 生成和校验配方的脚本不在仓库里 | 几百条配方必须靠脚本 |
| 测试 | 16 项回归测试 | 每条线、每台大机器都要有整线测试 |

## 12. 分阶段计划

规模只标相对大小，不承诺时间。每个阶段结束时模组都应该完整可玩。

| 阶段 | 内容 | 大机器 | 给原版 | 规模 |
| --- | --- | --- | --- | --- |
| 0 地基 | 机器基类、流体、对外接口、掉落表、本地化、清理旧代码、多方块框架雏形 | — | 漏斗能接机器 | 大 |
| 1 核心循环 | 工厂中枢与一、二星评级（用现有产品）；欠压降速；副产物堵塞；模具 | 选矿联合厂 | 电动修理台、电灯 | 中 |
| 2 吃 | 食品线、畜牧线、陶瓷玻璃线前半（砖、瓶）；纸箱最简版 | 隧道窑 / 隧道烤炉 | 自动畜舍、食堂、建材机 | 大 |
| 3 穿与用 | 纺织服装线、造纸印刷线；订单板；三星评级 | 长网造纸机、纺织联合车间 | 工装、打包箱、印刷机 | 大 |
| 4 精细 | 日化制药线、陶瓷玻璃线后半（光学玻璃、瓷器）；裂变反应堆补完；四星评级 | 精馏塔、灌装流水线 | 酿造车间、调色机、烟花机 | 大 |
| 5 终局 | 终局机器；五星评级；终局后的订单与装饰 | 终局机器 | — | 大 |

阶段 0 和阶段 1 无论方向如何都值得做。阶段 1 结束时能验证两件事：「持续产出」的评级玩法是否成立，多方块框架是否撑得住。两者都成立再展开阶段 2。

## 13. 需要先确认的选择

1. **终局机器**：瓶中世界（建议，需先做原型）、命名卫星、极光塔、天文钟楼，或其他想法。
2. **主线顺序**：先做「吃」（食品、畜牧）还是先做「穿与用」（纺织、造纸）。建议先做吃，因为它和现有的种植机衔接最顺。
3. **订单是否用绿宝石结算**：能接入原版经济，但等于让工厂变成绿宝石来源，会影响原版平衡。
4. **现有内容怎么处理**：太阳能阶梯、电路板配方是否保留原样作为「凑合」路线，还是按新线重做。
5. **物流**：建议只开放接口给漏斗和其他模组，自己不做传送带和管道。
6. **热量系统**：建议先不做完整系统，只把余热当作副产物。

## 14. 风险

- **范围很大。** 六条主线加五台以上大机器，是现有内容的数倍。必须按阶段推进，每阶段可独立发布。
- **多方块是技术风险最高的部分。** 所以把最简单的一台放在阶段 1，尽早暴露问题。
- **终局机器的渲染没有验证过。** 在阶段 3 之前应当做出原型，不行就换备选方案。
- **评级玩法没有现成先例。** 速率怎么测、断供怎么算、多人如何共享，都要在阶段 1 用最小版本试出来。
- **交织过头会劝退。** 六条线互相依赖，开局容易卡死。每条线的「凑合」路线必须只依赖原版物品和上一阶段的东西。
- **数值平衡。** 对原版有用的设备（酿造车间、修理台、打包箱、带效果的工装）都可能过强，需要逐个定代价。
